# かなノート (Kana Note)

เว็บแอปฝึก **เขียน ฟัง และพูด** ภาษาญี่ปุ่นบน iPad ใช้ Apple Pencil เขียนลงช่องกระดาษแบบญี่ปุ่นได้โดยตรง
มีระบบชื่อผู้ฝึก เลเวล (LV) ยศ และภารกิจประจำวัน ไม่ต้องติดตั้งอะไร เปิดผ่าน Safari แล้วเพิ่มลงหน้าจอโฮมได้เลย

## ฟีเจอร์

**ฝึก**
- ชุดฝึก: ฮิรางานะ คาตาคานะ (เลือกรวมเสียงขุ่น ゛゜ ได้) และคำศัพท์พื้นฐาน 28 คำ
- เขียน: 3 วิธี คือ เขียนทับรอย, ดูแล้วเขียนเอง, ฟังแล้วเขียน พร้อมให้คะแนนและตรา はなまる / 〇 / △
- ฟัง: ฟังเสียงแล้วเลือกคำตอบจาก 4 ตัวเลือก
- พูด: ฟังตัวอย่าง แล้วให้ระบบรู้จำเสียงตรวจ หรืออัดเสียงตัวเองไว้ฟังเทียบ

**ระบบผู้เล่น**
- ตั้งชื่อผู้ฝึกตอนเปิดครั้งแรก แก้ไขได้ในหน้าภารกิจ
- เก็บ XP จากทุกการฝึกเพื่อเพิ่ม LV ได้ไม่จำกัด (XP ที่ต้องใช้ต่อเลเวล = 40 + 20 × LV)
- ยศเลื่อนตาม LV แสดงเป็นตราประทับ (ハンコ)

| LV | ยศ |
|---|---|
| 1 | 入門 ผู้เริ่มต้น |
| 5 | 見習い ศิษย์ฝึกหัด |
| 10 | 学徒 นักเรียน |
| 15 | 書生 ศิษย์พู่กัน |
| 20 | 初段 สายดำขั้นหนึ่ง |
| 25 | 達人 ผู้เชี่ยวชาญ |
| 30 | 師範 ครูผู้สอน |
| 40 | 名人 ปรมาจารย์ |

- ภารกิจประจำวัน 3 ข้อ (เขียน ฟัง และพูดหรือเขียนเพิ่ม) เปลี่ยนชุดใหม่ทุกเที่ยงคืนตามเวลาเครื่อง ทำครบทั้ง 3 ข้อได้โบนัส +60 XP
- นับจำนวนวันที่ฝึกต่อเนื่อง และสถิติรวม

ข้อมูลทั้งหมดเก็บใน `localStorage` ของเบราว์เซอร์ในเครื่องนั้น ๆ ไม่มีการส่งขึ้นเซิร์ฟเวอร์

## เอาขึ้น GitHub Pages

1. สร้าง repository ใหม่บน GitHub เช่น `kana-note` (ตั้งเป็น Public)
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ (กด **Add file → Upload files** แล้วลากทั้งโฟลเดอร์ หรือใช้ git ด้านล่าง)
3. ไปที่ **Settings → Pages** เลือก Source เป็น **Deploy from a branch**, Branch `main`, โฟลเดอร์ `/ (root)` แล้วกด Save
4. รอประมาณ 1 นาที แอปจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/kana-note/`

```bash
git init
git add .
git commit -m "かなノート: ฝึกเขียน ฟัง พูดภาษาญี่ปุ่น"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/kana-note.git
git push -u origin main
```

## ใช้บน iPad

1. เปิดลิงก์ GitHub Pages ใน **Safari**
2. แตะปุ่มแชร์ แล้วเลือก **เพิ่มไปยังหน้าจอโฮม** จะได้ไอคอน かな เปิดแบบเต็มจอเหมือนแอป
3. หลังเปิดครั้งแรก แอปใช้งานออฟไลน์ได้ (ยกเว้นการรู้จำเสียงพูดที่ต้องใช้อินเทอร์เน็ต)

การฝึกพูดต้องอนุญาตไมโครโฟน และเปิด **Siri หรือการป้อนตามคำบอก** ใน การตั้งค่า → ทั่วไป → แป้นพิมพ์ ถ้าไม่มีเสียงพูดภาษาญี่ปุ่น ให้ดาวน์โหลดเสียงที่ การตั้งค่า → การช่วยการเข้าถึง → เนื้อหาที่พูด → เสียง → ภาษาญี่ปุ่น

## โครงสร้างไฟล์

```
index.html             หน้าแอป
css/style.css          หน้าตาและธีมสว่าง/มืด
js/data.js             ตัวอักษร คำศัพท์ ยศ ค่า XP และคลังภารกิจ
js/game.js             ชื่อผู้เล่น XP/LV ยศ ภารกิจประจำวัน
js/app.js              การเขียน ตรวจคะแนน ฟัง และพูด
sw.js                  ใช้งานออฟไลน์
manifest.webmanifest   ข้อมูลสำหรับติดตั้งลงหน้าจอโฮม
icons/                 ไอคอนแอป
```

## ปรับแต่ง

- เพิ่มคำศัพท์: แก้รายการ `VOCAB` ใน `js/data.js` รูปแบบ `['คำ', 'romaji', 'ความหมาย']`
- ปรับ XP ที่ได้: แก้ค่า `XP` ใน `js/data.js`
- เพิ่มหรือแก้ยศ: แก้ `RANKS` ใน `js/data.js`
- เพิ่มภารกิจ: เพิ่มรายการใน `QUESTS` (กำหนด `group`, `ev`, จำนวน `n`, `xp` และข้อความ)
- หลังแก้ไฟล์ ให้เปลี่ยนชื่อ `CACHE` ใน `sw.js` (เช่น `kananote-v3`) เพื่อให้เครื่องที่ติดตั้งแล้วโหลดเวอร์ชันใหม่
